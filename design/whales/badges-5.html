Non-color cues

  • NEW — code NW, trace starts on the baseline with a hollow first dot, word New.
  • ADDED — code AD, trace ends higher than it starts, filled end dot, word Added.
  • TRIMMED — code TR, trace ends lower than it starts, filled end dot, word Trimmed.
  • EXITED — code EX, trace drops to the baseline with a hollow end dot, word Exited.
  • HELD — code HD, trace is a flat horizontal line, word Held.
  • Covered — ticker is a link with a solid underline and a trailing › chevron.
  • Not covered — ticker is plain text with a dotted underline and the words not tracked.

Source: SEC EDGAR Form 13F-HR. Positions are as of quarter end and lag up to 45 days. Long US equity positions only — shorts, bonds and non-US holdings are not disclosed.

Concept Show the last four quarters of share count so the reader sees the trajectory, not just this quarter's delta. Trade-off: per-row normalisation means a 2.1% add and a 75% add can draw identical slopes — the trace tells a story but lies about size.
